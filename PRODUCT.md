# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Users

The primary user returns to a private media library throughout the day, moves between sources, and watches videos or looks through images. The app also serves people who only import files or connect one source.

## Product Purpose

Open the last library after unlocking. Make it easy to pick up where the user left off, find something new, and manage a connection when it needs attention. Rework the daily flows so the gallery feels like one app across sources.

## Positioning

One gallery for authorized Tato and Telegram libraries, web sources, and imported files. Media can be browsed on demand, while organization and supported offline copies live on the device.

## Operating Context

Common tasks are switching sources, restoring a view, searching by name or tags as supported, opening an image or video, returning to the grid, finding saved items, and checking downloads or connection status. Setup and troubleshooting start inside Gallery. Each source has its own search, catalog, and privacy rules.

## Capabilities and Constraints

- Keep the working library, viewer, playback controls, filters, saved searches, and offline workflows. The redesign covers navigation, search, the viewer, organization, downloads, settings, and source setup.
- Gallery keeps its network isolation. Telegram and Web should use one optional companion package. Tato continues to use its separately authorized connector.
- Keep source permissions and consent specific to the active account or site. Preserve encrypted local storage, PIN and biometric access, and source-specific retention rules. Respect Gelbooru's session-only media handling.
- Exercise updates and source migrations in an isolated lab using synthetic media. Preserve existing installation data and validate any required reauthorization before delivery.

## Brand Commitments

Dark, minimal and serious. Media takes priority and privacy is discreet. Use plain Spanish in the app and preserve the Gallery identity.

## Product Principles

- Opening the app returns the user to the library already in use.
- Navigation and control placement feel consistent across libraries.
- Source-specific controls are available in context, with a clear path back.
- Connection and download feedback is visible where it affects the task.
- Keep familiar video and image gestures accessible through alternatives for screen readers.
