# Gallery 2.18 and Telegram connector 1.1

This is the first public source-based distribution of these component versions.
It keeps their application versions and behavior and adds a dedicated production
signing identity. Public documentation is in English; the Android UI remains Spanish.

## Components and compatibility

| Component | Package | versionName | versionCode | Minimum Android | Release ABI |
| --- | --- | --- | --- | --- | --- |
| Gallery | `local.ttlab.gallery` | 2.18 | 20 | 12 / API 31 | arm64-v8a |
| Telegram connector | `local.ttlab.telegram` | 1.1 | 2 | 12 / API 31 | arm64-v8a |

Use both APKs from the same release in the same Android user or profile.
They must have the same signer for local permissions to work.
The gallery retains its existing restriction to Android user IDs 0, 14, and 15.

The production certificate is **CN=Media Gallery Android, O=Jhoan Marte**.
Its SHA-256 fingerprint is:

~~~text
77630993bd4c827266970a8ddd24dab4010eb7708a295b98cd41dbe4a99bd4d1
~~~

This certificate differs from the signer of the old lab builds. These APKs
cannot update those installations in place. Keep the old app and its data
until you have an encrypted backup and its passphrase and have planned the
migration. Cross-signer migration has not been tested.

- `THIRD_PARTY_NOTICES.txt`

Use the checksums attached to that release; the old private APKs have different
signatures and hashes. A draft without these files is not an installable release.

## Features and limits

Local imports and organization work without a service account. Telegram
requires your own API credentials and an account authorized in the connector.
Read the [setup guide](../../telegram/README.md) before connecting it.

The gallery supports on-demand playback, offline downloads, resume, bookmarks,
favorites, Watch later, albums, tags, recent history, archives, chat folders,
and encrypted backups that retain selected covers and pinned chats.

Visual features require the bundled pinned models and use local processing.
They do not run on Telegram in this version. No Tato client or connector APK
is part of this release; only its local interface is documented.
